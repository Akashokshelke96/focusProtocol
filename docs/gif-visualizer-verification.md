# GIF visualizer and video filters: implementation and verification

1. **White backgrounds:** The supplied GIFs already contained transparency. FFmpeg decoded transparent corner pixels as RGBA (255,255,255,0). The previous black colorkey replaced their alpha with 255, producing white boxes, and also removed legitimate black disc pixels.
2. **Transparency:** Removed the GIF colorkey. Preserve original alpha through lossless ARGB/QTRLE clips, converted once and cached by source hash, dimensions, and cache version. Original GIF files are untouched. Conversion validates alpha and duration. Opaque replacement assets fail explicitly instead of stripping legitimate white artwork.
3. **Disc size:** Multiplied the previous proportional disc width by 0.5, preserving aspect ratio. At 1920x1080 the disc is 113x113 rather than approximately 226x226. No design crop.
4. **Position:** Soundwave sits immediately left of the disc with a 6-pixel gap at 1080p. Their vertical centers align. The compact group is anchored at the lower right with configured proportional padding.
5. **Old waveform owner:** `_render_video` in `app/pipeline/long_form_jazz_orchestrator.py` previously called `app.video.waveform.create_waveform`.
6. **Old waveform removal:** The production render no longer calls that generator or adds its output to the graph. Metadata records waveform disabled. Legacy module remains for compatibility; old controls were removed from generation forms. Acceptance runs replace the old generator with a function that raises, proving it is not called.
7. **Toggle defect:** The previous filter graph built its base/output labels conditionally with the visualizer, leaving the disabled branch without a consistently connected video output.
8. **Toggle fix:** Always construct the background/base video and connect the final output. Add the GIF group as an optional step with correctly assigned input indices. Audio, filters, motion, watermark, subscribe overlays, and subsequent caption muxing retain their own controls. Legacy waveform toggle requests map to the new visualizer toggle.
9. **Filters:** Original, Vintage, Old Cinema, Warm Film, Faded Film, Noir, Sepia, Cool Cinematic, Film Grain, and Soft Vignette. UI exposes presets and intensity; zero intensity bypasses effects. Channel defaults and per-job overrides use existing settings/profile validation.
10. **Filter performance:** Static color treatment and static watermark are cached before repeating the still background. Temporal grain/old-film effects run per frame. Animated GIF composition happens at the small group dimensions before a single full-video overlay. Configured output FPS and encoder quality are preserved.
11. **Bottlenecks:** Repeated full-frame color conversion and static background/watermark processing were avoidable costs. The optimized 10-minute 1080p/30 FPS Vintage render completed in 54.205 seconds. Recorded renderer peak RAM was 387 MB, GPU memory 181 MB, GPU temperature 51 C; system RAM was already about 88% occupied. These are measurements for this machine/profile, not a guarantee for all effects or motion modes.
12. **Other safe improvements:** Segment reuse now checks a command/input fingerprint in addition to duration, preventing stale results after changing filters, toggle state, or source assets. GIF caches preserve source timing (disc 3-second loop; soundwave 0.8-second loop). Segment seek offsets maintain their loop phase.
13. **Actual videos:** Completed real 3-minute and 10-minute render-path tests at 1920x1080/30 FPS, plus short Original/Vintage/Noir/Sepia and visualizer-off motion/caption cases. FFprobe and existing output/QC validation checked the outputs. Inspected rendered frames confirm transparency, circular disc, compact positioning, and animation. Dark and light background composites passed pixel checks. The 90-minute test was stopped at the user's request; no further 90-minute test will be run. Its partial files are not an accepted output.
14. **Regressions:** Python compilation passed. `pytest tests -q`: 110 passed, 1 skipped. Studio UI Node checks passed. Existing asset hash validation passed; designated thumbnail and background originals remain unchanged. Caption-off/on behavior was checked through the existing subtitle mux path. No live YouTube upload was performed. Broad root-level pytest collection cannot complete because two legacy test modules require missing librosa.
15. **Remaining limits:** Ninety-minute stability is not certified by this change. Completed acceptance QC reports warning rather than failure because the preserved source thumbnail exceeds YouTube's 2 MB upload size; this is existing behavior and no resizing was performed. All filter presets have configuration/filter tests; actual image comparisons cover Original, Vintage, Noir, and Sepia. Motion/caption and Studio handlers were checked, but no new live browser or live publishing end-to-end session was completed. A full orchestrator job from creation through music selection was not rerun in this acceptance batch; actual render, validation, and caption paths used prepared local media.

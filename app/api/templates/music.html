Treblo API Configuration
Treblo API Key Required
Add TREBLO_API_KEY to your .env file to enable music generation.

How to get your Treblo API key:

  1. Visit https://treblo.com/developers
  2. Sign up or log in to your account
  3. Navigate to API Keys section
  4. Create or copy your API key
  5. Add to .env: TREBLO_API_KEY=your_key_here
